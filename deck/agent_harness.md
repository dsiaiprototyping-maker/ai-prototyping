Choosing the right model
Suggested slide title
LLM Chat vs AI Agent Harness

Simple comparison for the slide

LLM / Chat Interface	AI Agent Harness
You ask a question, it gives an answer	You give a goal, it can take actions to achieve it
Mostly conversation	Conversation plus tools, memory, permissions, and workflows
Best for brainstorming, writing, summarising	Best for building, checking, testing, fixing, and iterating
Human does most of the execution	Agent can do parts of the execution under supervision
Output is usually text	Output can be code, edits, screenshots, test results, PRs, browser actions
Examples row

Claude / Chat UI: strong for thinking, explaining, drafting, refining
Claude Code / Codex: strong for acting inside a working environment with files, tools, terminal, browser, and review loops
One-line takeaway
A chat interface gives you answers. An agent harness helps turn answers into completed work.
