Suggested slide title
Claude Desktop App — Three Ways to Work

Simple comparison for the slide

Chat	Projects (CoWork)	Claude Code
One-off conversation	Persistent workspace	Agent inside your codebase
No memory between sessions	Shared context across sessions	Reads, edits, and runs files
Best for questions and drafts	Best for ongoing team work	Best for building and iterating
Output is text	Output is text plus files	Output is code, tests, PRs, terminal actions
You drive everything	Claude remembers your project	Claude acts with your supervision

Essential differences row

Chat: stateless — great for quick thinking, summarising, explaining
Projects: stateful — great for collaborations that span days or weeks, shared with teammates
Claude Code: agentic — great for software tasks where Claude needs to see and change real artefacts

One-line takeaway
Chat answers your question. Projects remembers your work. Claude Code does the work with you.
